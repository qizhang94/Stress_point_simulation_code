Here, the parameters are adopted based on the experimental tests on Tournemire shale (Niandou et al., 1997; Zhao et al., 2018): $\lambda^e = 4270$ MPa, $\mu_T = 9360$ MPa, $\mu_L = 6510$ MPa, $a^e = -1870$ MPa, $b^e = 5420$ MPa, $M = 1.07$, $\lambda^p = -0.0026$, $c_1^p = 0.7$, $c_2^p = -0.36$, and $c_3^p = 0.6$. The bedding plane angle is $\pi/3$ in the $x {\rm O} y$ plane, which leads to the bedding normal vector (column vector) in 3D as **_n_** = [-sin($\pi$/3); cos($\pi$/3); 0].

For this test, the mean stress is **also projected to the fictitious stress space** and then substituted into the MCC yield function. **Sometimes**, people would directly use the mean stress (Semnani et al., 2016). Note for stress projection, we could also use $\alpha^p = c_1^p + c_2^p + c_3^p$, $\beta^p = c_1^p$, $\gamma^p = c_1^p + 0.5*c_3^p$.

Sometimes it would be better to rewrite the five elastic constants in terms of Young's moduli and Poisson's ratios, as they have more physical meanings than $a^e$ or $b^e$. The converted results are shown here. $E_v = 12860$ MPa, $E_h = 21900$ MPa, $\nu_{hv} = 0.15$, $\nu_{vh} = \nu_{hv}/E_h \times E_v$, $\nu_{hh} = 0.17$, and $G_{vh} = 6510$ MPa.
